Chronos · one page

A FRESHNESS FIREWALL INSIDE THE GATEWAY

Chronos is a Go plugin compiled into Bifrost's own binary, plus a Python service that does the slow work out of band. Every answer — fresh or replayed from the semantic cache — has its time-sensitive claims pulled out, checked against the live web, and scored. A cache entry behind an answer that has gone stale is deleted.

The decision that shapes everything else The plugin compiles as a package of Bifrost's own transports module — same go.mod, same toolchain, same flags — so a Go plugin ABI mismatch is structurally impossible.
What it costs The image builds the gateway from source: several minutes the first time. The gateway must be linked dynamically, so a static build is rejected during the build.
Added latency A fresh answer is verified in a goroutine and waits for nothing. A cache hit — the only answer that can be stale — is checked inline: 28 ms with a warm claim cache.
